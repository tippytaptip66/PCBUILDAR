# 3D models go here

Put raw model files in `Components/<Category>/` (FBX preferred), at real size (1 unit = 1 m).
Wrap each one in a prefab in `Assets/_Project/Prefabs/Components/` with ExplodableModel + ModelHotspot children.
Then set that prefab on the component's asset in `Data/Resources/Components`.
Full walkthrough: `Assets/_Project/BUILDAR_GUIDE.md`, section 2.
